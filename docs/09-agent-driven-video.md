# 09 · Agent 驱动视频生成（未来 3 年趋势）

> 核心判断：Agent 不只用于"优化 kernel"，而是渗透到视频生产全链路——从创意、分镜、生成、剪辑、质检到自我迭代。这是确定性趋势。

## 9.1 为什么是必然

1. **视频生成本质是长链条决策**：剧本→分镜→镜头→生成→音画对齐→剪辑→质检，每步都有选择与回溯，天然适合 Agent 编排，而非一次性 prompt。
2. **单模型能力已强但"不会做事"**：H3 解决了"单个镜头质量"，但"把一个故事做成"仍需大量人工串联——这正是 Agent 的空间。
3. **已有原始证据**：
   - **Sol-Engine 的 RSI / skill agents**：并行 agent 搜索 kernel 融合/布局/通信 + integrator 汇总 + 数值/人工门控（arXiv:2606.23743）。
   - **KDA / Humanize / AlphaEvolve / AccelOpt**：agent 化算子优化与科学发现。
   - 多智能体工作流（如我们已验证的 5 路并行研究）已能独立完成系统调研。

## 9.2 Agent 在视频链路的六个层级

| 层级 | Agent 角色 | 现状 |
|---|---|---|
| L1 创意/剧本 | 编剧 agent：选题、脚本、台词、风格 | 已成熟（LLM） |
| L2 分镜/调度 | 导演 agent：分镜、机位、时长、转场 | 部分成熟 |
| L3 生成编排 | 调度多模型：T2V/I2V/pose/音频，选 checkpoint、参数、seed | 起步（Sol-Engine 范式） |
| L4 音画/一致性 | 保证跨镜头身份、唇形、音乐踩点、长程连贯 | 研究中（VDN/骨架/缓存） |
| L5 质检/修复 | 自动评估（VBench/真凭据）、发现崩坏帧、局部重生成 | 起步，价值最大 |
| L6 自我改进 | RSI：自动优化 kernel/管线并验证，失败回滚 | 已验证（Sol-H3） |

## 9.3 三种 Agent 架构形态

1. **编排型（Orchestrator）**：一个主 agent 调度多个专用模型/子 agent，串行/并行接力。
   - 适合：完整短片生产；类似 Sol-Engine 的 integrator 模式。
2. **递归自我改进型（RSI）**：Agent 在"生成→评测→优化→验证"闭环里迭代算子与流程。
   - 关键：评价函数质量决定上限，需 fail-closed + 数值门控 + 人工为证（防奖励黑客）。
3. **多智能体并行型**：多个 agent 并行出方案/镜头，cherry-pick 合成。
   - 适合：多候选、A/B、规模化产出。

## 9.4 未来 3 年路线推断

- **第 1 年**：Agent 编排多模型出完整短片成为主流工作流（L1–L3 打通），工具链标准化。
- **第 2 年**：自动质检与局部修复闭环成熟（L4–L5），"提示→成片"人力大幅退出。
- **第 3 年**：Agent + 实时流式生成 → 可交互内容生产；RSI 让管线在目标硬件上自动调优（L6 常态化）。

## 9.5 关键风险与治理

1. **评价即上限**：没有真凭据/可验证指标，agent 会"自报成功"（我们已多次遇到子代理注水）。
2. **错误累积**：多 agent、cache、量化叠加会漂移，需逐段真机核验 + 失败回滚。
3. **成本失控**：递归调用与多候选烧算力，需预算/串行接力（尤其边缘 OOM 约束）。
4. **治理原则**：真凭据 over 自报、bit-exact 与近似分离、人类掌握发布闸门。

## 9.6 与本调研其他趋势的关系

- Agent 是**横切层**：驾驭混合注意力、AR-扩散统一、世界模型、流式与边缘部署。
- 终局：**Agent 编排的统一多模态世界模型，可流式、可交互、能自我优化**——第 08 章的架构主轴 + 本章的执行主体，两者合流。
