# 10 · 如何从技术与工程角度做视频生成

> 定位：不讲"有哪些模型"，讲"动手做"的分层、顺序、技术决策与坑。
> 两条现实路线：**A 工程集成/微调开源底座**（推荐，99% 的人该走）；**B 自研训练**（需大规模算力）。

## 10.1 先建立分层认知（视频生成的完整栈）

```
数据 → VAE/Tokenizer(压缩) → Patchify → DiT Backbone(注意力+条件)
     → Scheduler(多步采样) → VAE Decode → 音画合成 → MP4
```

每一层都是独立的工程决策点；质量和成本在不同层产生。

| 层 | 决定什么 | 主流选择 |
|---|---|---|
| 数据/字幕 | 能力上限、对齐质量 | 视频+结构化描述；清洗、切镜、打标 |
| VAE | token 数=成本下限 | 高压缩视频VAE（空间16–32×/时间4–8×）、音频VAE |
| Backbone | 质量 vs 显存 | DiT；Full/混合/线性注意力 |
| 条件注入 | 可控性 | cross-attn / AdaLN / ControlNet |
| Scheduler | 步数 vs 质量 | DDIM/Flow/DPM + 蒸馏少步 |
| 解码/合成 | 落地 | 并行/分块 VAE、音画对齐、ffmpeg |

## 10.2 推荐路线 A：基于开源底座做工程集成（务实）

**原则：不重训，站在 H3/Wan/LTX 等开源底座上做"编排+适配+加速+质检"。**

按顺序做：

1. **选底座**：按显存与任务（见 06/07 章）。8GB→Wan5B/LTX-Video；24GB→多数768p DiT/H3(offload)；服务器→H3/LTX-2.5。
2. **跑通官方 pipeline**：拿到真实输出再优化，先不要魔改。
3. **做适配层**：ControlNet（pose/depth）、LoRA（风格/角色）、参考图、音频条件——这些是低成本高价值。
4. **上加速**（按栈顺序）：少步蒸馏 LoRA → 稀疏注意力/cache → 选择性量化 → kernel 融合。每步都做 A/B 与数值核验。
5. **做编排**：多模型/多镜头串行或并行接力，中间产物落盘，失败可回滚。
6. **加质检闭环**：自动评估 + 崩坏帧检测 + 局部重生成。
7. **稳定服务**：常驻权重、批处理、显存看门狗、日志与回放。

## 10.3 路线 B：自研训练（需大算力，研究向）

顺序（不要颠倒）：

1. **数据管线先行**：收集→切镜→去重→质量过滤→生成/清洗结构化字幕。这是最贵也最决定上限的环节。
2. **选/训 VAE**：先冻结或复用成熟 VAE；重建质量与压缩率要单独评测（PSNR/SSIM + 主观）。
3. **建 DiT**：从小规模起步验证；选注意力策略——预算紧就用混合注意力（局部softmax+全局线性）。
4. **条件与位置编码**：文本编码器、AdaLN；多模态需统一物理时间轴（关键难点）。
5. **预训练**：大规模视频 + 多任务（T2V/I2V/编辑）混合。
6. **后训练**：质量微调、RLHF/偏好、CFG。
7. **蒸馏与部署**：少步、量化、目标硬件 kernel 优化。

**铁律：先在小数据/小模型上把整条链跑通（thin-slice），再放量。**

## 10.4 工程关键决策

### 内存（边缘生死线）
- 显存放不下就**分层 offload**（仅当前组件驻留），但要意识到 offload 会慢一个量级。
- 多模型拆独立进程、单训→打分落盘→离线合成；设可用内存看门狗（如 <650MB 即停）。
- AdaLN/条件预算缓存是零代价优化（H3 靠此省 ~24GB）。

### 量化（selective，不要一刀切）
- 首尾/敏感层保持高精度；投影层可 FP8/NVFP4。
- 量化必须与 kernel 融合协同，否则被数据搬运吞掉收益。
- 明确区分 bit-exact（布局）与近似（算术）。

### 并行
- 单卡内：分块/批处理 VAE、torch.compile。
- 多卡：Ulysses/上下文并行；通信打包、低比特传输（INT8 QKV/FP8 out）。

### 评测（真凭据）
- 不只看 AUC/FID：用 P@k、VBench、真实桶测试、逐帧检查。
- 预测/目标/验证日期链严格区分；所有改动有对照、可回滚。
- 拒绝"自报成功"，agent/子任务产物必须真机复核。

## 10.5 分阶段交付节奏

| 阶段 | 目标 | 通过标准 |
|---|---|---|
| S0 thin-slice | 最小配置出一个片段 | 真实文件可播放 |
| S1 单镜头质量 | 官方基线复现 | 指标对齐官方 |
| S2 可控/加速 | 条件+少步+量化 | A/B 无损或可接受 |
| S3 多镜头编排 | 完整短片 | 一致性/质检闭环 |
| S4 服务化 | 稳定可部署 | 内存/延迟/回滚 |

## 10.6 一句话方法论

**先跑通、再拆分；小模型验证链路，大模型只补关键；每一步都用真实证据说话，把失败设计成可回滚。**
