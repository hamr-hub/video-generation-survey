# 04 · 架构对比分析

## 4.1 H3 先进在哪（准确判断）

核心进步**不是新算子，而是"单一 DiT 流统一所有模态+任务"的工程完成度**。

1. **一条 DiT 流联合去噪文本/画面/立体声**：视频与音频 token 同批去噪，对白唇形、环境音同步质量碾压旧方案。
2. **大胆保留 Full Attention**：约 37,700 token 行仍用完整 softmax，换来主体身份、场景布局、跨镜头时序的远距离不漂移。反潮流（同期 LLM 都在砍注意力，MiniMax 在 M2/H3 回归全注意力并验证收益）。
3. **AdaLN 巨型调制**：50 层 AdaLN 约 13B、占 39%，用调制统一注入多任务/多模态控制。
4. **模态入口与 VAE**：Qwen3-VL + 两层 Token Refiner；音频 32kHz→40Hz，左右声道独立。
5. **可蒸馏/可加速生态位**：CFG 蒸馏、FastH3、Sol-H3 证明"既大又能被压"。

**H3 的代价**：33B + Full Attention → 极重，49 次前向，边缘无望。优势是质量上限而非效率。

## 4.2 四种注意力架构横向对比

| 架构 | 长程身份/布局 | 显存/速度 | KV cache | 主要问题 | 代表 |
|---|---|---|---|---|---|
| **Full Softmax** | 最强 | 最贵，O(N²) | 随长度膨胀 | 算力/显存 | H3 |
| **Sparse** | 强（重要块精确） | 省，训练免 | 需在线判块 | 阈值/数值近似 | Sol-Attn、SageAttn |
| **Linear（纯）** | 弱，易丢身份 | 最省，O(N)，恒内存 | 压缩为状态 | 长序列全局特征漂移 | SANA-Video |
| **Hybrid（混合）** | 近无损 | 大幅省 | 局部精确+全局线性 | 分支校准/训练复杂 | VDN、SANA-Video 2.0、SLA |

## 4.3 Video DeltaNet（VDN）深度——最有力的效率架构

**论文**：arXiv 2609.20744（UC Berkeley + Impossible）。把混合注意力做成"视频原生"。

- **局部 Softmax**：邻近帧（5 帧一块）走精确 token 注意力，保近处身份/唇形/音画。
- **双向线性记忆**：远处上下文走双向线性注意力，文本在初始化时用 delta rule 写进前向+反向状态（各一半，合计恰好一次）。
- **核心创新 Video Delta Attention (VDA)**：把标准"逐 token 更新状态"改成**逐帧联合求解**——一帧内所有空间 token 一起解一个 normal equation（联合正规方程），而非逐个做冻结状态的梯度步。解决了 LLM 线性注意力直接搬到视频的三个水土不服（token 序 vs 帧、需双向、身份保持）。
- **分支独立门控/投影**：Softmax 与 Linear 输出尺度不同，各自 RMSNorm + sigmoid gate + 独立 W_O，再合并进残差流。
- **适配预训练 H3**：先冻结 softmax 主干/QKVO/FFN，只联合训练线性支路 + QKVO LoRA（A1 逐层→A2 端到端），避免随机支路扰动；B 阶段才全量。

**实测**：单层 332.5ms → VDA+滑窗 192.1ms → +优化kernel+FP8 125.3ms（**2.65×**）；只加 3.57% 注意力密度即稳住长程。8×B200 出 14.4s 片约 9s（快于播放）。

## 4.4 SANA-Video 2.0：Attention Residual 路线

- 混合线性/softmax + **Attention Residual**（注意力残差），5B 720p 质量匹敌全 softmax DiT。
- 编译 DiT 前向在 720p/60s 比对照全 softmax **快 3.2×**，且差距随时长扩大。
- 与 VDN 思路同源：精确注意力保关键局部，线性管全局。

## 4.5 架构趋势判断

1. Full Attention 现在被当作**昂贵资源，按位置策略性使用**，而非到处铺。
2. **"局部精确 + 全局线性 + 逐帧记忆更新"**是视频高效架构当前最被看好的形态。
3. 纯线性在视频上单独不够（身份/布局），混合是必由之路。
4. 对 7GB 边缘：H3/VDN 都太大；可迁移的是**思想拆分**（精确保近、线性管远、两阶段），不是代码。
