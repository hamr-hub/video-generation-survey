# 视频生成 → 世界模型 / 物理一致性 / 具身：论文调研

> 范围：SANA-WM、NVIDIA Cosmos、Genie 1/2、UniSim、GameNGen，以及 Sora 作为“世界模拟器”的技术叙事。本文只采用论文、官方项目页/博客与可核查二手资料；DeepMind 未公开 Genie 2 论文的部分明确标注“未公开/查不到”。

## 0. 先给结论

通用视频生成模型的目标是：给定文本/图像，生成一段看起来合理的视频；它通常是**开环、一次性、短时序**的。生成式世界模型的目标是：给定持续到来的动作、相机轨迹或干预，持续预测环境观测，并让同一物体、场景布局、物理状态和因果后果在长时序中保持一致。

因此，世界模型不是“更长的视频生成器”这么简单。它至少多出四类要求：

1. **逐步条件接口**：动作/相机/状态在每个时间步进入模型，而不是只在开头给一次文本。
2. **状态与记忆**：能记住离开视野的物体、已经发生的场景改变、3D 布局和长期身份。
3. **闭环长程一致性**：自回归滚动时抑制误差累积，重访地点时保持几何、外观和状态一致。
4. **可用于决策的交互语义**：动作必须导致稳定、可区分、可重复的后果；用于具身时还要支持策略学习和 sim2real 验证。

## 1. SANA-WM：高效分钟级、6-DoF 相机控制世界模型

- **论文**：*SANA-WM: Efficient Minute-Scale World Modeling with Hybrid Linear Diffusion Transformer*
- **编号**：arXiv:2605.15178v1，2026-05-14
- **机构/作者**：NVIDIA；Haoyi Zhu、Haozhe Liu、Yuyang Zhao、Tian Ye 等，基于 NVlabs SANA/SANA-Video 系列
- **定位**：输入首帧、文本与 6-DoF 相机轨迹，原生生成 1 分钟、720p、相机可控视频

### 核心机制

1. **2.6B 参数 Hybrid Linear DiT**
   - 帧级使用 **Gated DeltaNet（GDN）**做线性/门控循环式上下文聚合；
   - 周期性插入 **softmax attention**，保留精确的长程召回能力；
   - 目标是在分钟级 token 数下降低显存与计算开销。

2. **高压缩视频 tokenizer**
   - 使用高压缩率的 LTX2 tokenizer，减少分钟级 720p 视频的 token 数。

3. **双分支相机控制**
   - latent-rate UCPE 分支：捕捉全局轨迹结构；
   - raw-frame Plücker mixing 分支：在时间 VAE stride 内恢复细粒度相机运动；
   - 这种 coarse-to-fine 设计用于抵抗强压缩造成的位姿信息损失。

4. **两阶段生成**
   - 第一阶段生成完整长视频；
   - 第二阶段独立 long-video refiner 修正结构伪影、锐化细节，并改善整段一致性。

5. **鲁棒相机位姿标注管线**
   - 从公开视频中通过位姿/几何估计器恢复 metric-scale 6-DoF pose；
   - 过滤后得到约 **213K** 带位姿监督的公开视频片段。

6. **三种推理形态**
   - bidirectional：高质量离线合成；
   - chunk-causal autoregressive：顺序滚动；
   - distilled few-step autoregressive：低延迟部署。

### 实测结果（论文/官方项目页声称）

- 原生训练 1 分钟生成，而非只从短视频模型蒸馏；
- 训练数据：约 **213K** 公开视频片段；
- 训练成本：**15 天 × 64 张 H100**；
- 推理：双向/chunk-causal 版本可在单张 H100 内完成；
- 蒸馏 + NVFP4 量化：单张 RTX 5090 上去噪一段 60 秒 720p 视频约 **34 秒**；
- 论文称在动作跟随上强于此前开源基线，视觉质量可与大规模工业基线（LingBot-World、HY-WorldPlay）比较，同时吞吐最高高 **36×**。

### 局限与注意事项

- 论文的“世界模型”主要指**相机轨迹控制的世界建模**：首帧 + 文本 + 6-DoF camera trajectory；它不是键盘/机械臂动作驱动的通用可交互环境。
- 对场景中物体被持续操作、可变形物体、接触物理、可编辑状态等能力，论文摘要与方法没有给出与交互式世界模型同等级的闭环实验；不能外推。
- 对比的工业基线和评测基准较新，公开可复现实验与第三方独立评测仍需等待。

### 与通用视频生成模型的架构差异

- 多了显式 **6-DoF metric pose**条件，而且分为 latent 全局轨迹与帧内 Plücker 细粒度两个分支；
- 原生面向一分钟长上下文，而非几秒 clip；
- 使用线性/门控循环记忆与周期性 softmax attention 的混合架构，突出长序列效率；
- 同时提供双向离线生成和因果/分块因果滚动两种部署形态。

## 2. NVIDIA Cosmos：面向 Physical AI 的世界基础模型平台

- **论文**：*Cosmos World Foundation Model Platform for Physical AI*
- **编号**：arXiv:2501.03575；v1 2025-01，v3 2025-07
- **机构**：NVIDIA，数十位作者联合
- **定位**：不是单一视频模型，而是包含数据治理、tokenizer、预训练世界模型、后训练样例、安全护栏的开放平台

### 平台组成

1. **视频治理管线**：镜头切分、质量/运动/字幕/类型过滤、VLM 标注、语义去重和分片。
2. **世界基础模型（WFM）**：同时提供扩散式与自回归式两条技术路线。
3. **视频/图像 tokenizer**：连续 token 与离散 token，多压缩率，因果设计。
4. **后训练示例**：相机位姿控制、机器人操作、自动驾驶。
5. **Guardrails**：输入与输出安全过滤。

### 数据规模

- 原始视频约 **20M 小时**，分辨率主要为 720p 到 4K；
- 抽取约 **100M** 个 2–60 秒片段；
- 数据类别覆盖驾驶、手部操作、人体活动、导航/空间感知、第一视角、自然动态、动态相机和合成渲染等；
- 论文显式排除了部分游戏、动画和抽象视觉内容，以服务真实物理世界建模。

### 模型与核心架构

#### 2.1 扩散式 WFM

预训练分两步：

1. **Text2World**：从文本生成视觉世界；
2. **Video2World**：基于过去视频和文本预测未来视觉世界。

公开发布的 Cosmos-Predict1 扩散模型包括：

- 7B / 14B Text2World；
- 7B / 14B Video2World；
- 7B WorldInterpolator，用于生成更平滑、更高 FPS 的视频段。

#### 2.2 自回归式 WFM

- 先做 vanilla next-token / foresight generation；
- 再做文本条件的 Video2World；
- 公开模型包括 **4B、12B** 未来世界生成模型，以及 **5B、13B Video2World** 模型。

#### 2.3 因果 tokenizer

- 在小波空间中编码；
- 使用时空分解 3D 卷积、因果时间卷积与因果时间注意力；
- 当前帧 token 不依赖未来帧；
- 因果 tokenizer 能把单帧图像当作长度为 1 的视频，从而支持图像—视频联合训练。

论文发布的 tokenizer 在 TokenBench、DAVIS 等数据上以 PSNR、SSIM、rFID/rFVD 等指标评估；论文报告其重建质量优于多种现有 image/video tokenizer，并可在单张 A100 80GB 中一次编码 8 秒 1080p 或 10 秒 720p 视频。

### 后训练与实测方向

- **相机控制**：将 WFM 微调为 camera-pose conditional，得到可导航虚拟世界；
- **机器人操作**：用 video-action 序列微调，改善给定机器人动作后的未来状态预测；
- **自动驾驶**：面向驾驶场景的未来预测/仿真微调。

### 局限

- 论文自己明确表示“世界基础模型问题仍远未解决”；
- Cosmos-Predict1 更像一套可后训练的基础模型和工具链，通用预训练模型本身不等于某一具体机器人或驾驶任务的高保真模拟器；
- 论文平台中的不少能力通过后训练体现，真实物理精度、接触动力学、长时状态持久性仍需下游数据和评测支撑；
- 主要输出视觉观测；未见其在论文中提供完整的多传感模态（力觉、触觉、音频等）统一闭环仿真。

### 与通用视频生成模型的差异

- 明确采用“**预训练通用 WFM → 下游 Physical AI 后训练**”范式；
- 同时布局连续扩散和离散自回归两条路线；
- tokenizer 因果化，与真实世界时间顺序和机器人在线输入对齐；
- 训练目标从文本生成视频扩展为过去观测 + 文本/动作/位姿 → 未来世界；
- 数据治理强调物理丰富动态，而不只是审美或叙事质量。

## 3. Genie 1：从无标签视频学习可交互环境

- **论文**：*Genie: Generative Interactive Environments*
- **编号**：arXiv:2402.15391；ICML 2024
- **机构**：Google DeepMind
- **训练数据**：约 **30,000 小时**互联网 2D 平台游戏视频；另有基于 RT1 无动作机器人视频的独立模型实验

### 核心机制

Genie 由三个模块组成：

1. **Spatiotemporal Video Tokenizer**
   - 将原始视频帧编码为离散视觉 token；
   - 结合空间与时间信息，降低逐帧独立 tokenizer 的不稳定性。

2. **Latent Action Model（LAM）**
   - 不使用人工动作标签；
   - 从相邻帧中推断离散潜在动作；
   - 论文配置中潜在动作码数量为 **8**；
   - 轻量解码器直接从像素学习动作，比让大动力学模型兼任动作推断更稳定。

3. **Autoregressive Dynamics Model**
   - 基于过去视觉 token 与潜在动作，预测下一帧 token；
   - 使用 decoder-only **MaskGIT** transformer；
   - 训练时对未来/目标 token 按随机 mask rate 进行掩码预测。

推理时，用户给出一个离散 latent action，模型生成下一帧，从而把单张提示图或文本生成的场景变成可逐帧操作的 2D 环境。

### 实测结果

- 可从文本、图像或草图生成类似 2D 平台游戏的可玩环境；
- 在无动作标签视频中学到可控 latent action；
- 同一动作重复执行可产生相对一致的前景/背景运动效果；
- 论文还展示 latent action 可用于给未见专家视频打标签，并训练模仿学习策略；
- 总参数规模常见报道为 **11B**（该数字来自论文/公开资料的汇总；具体模块参数与论文版本表述需查正文表格）。

### 局限

- 推理速度约 **1 FPS**，远不能支持实时交互；
- 主要是 2D、风格化平台环境，分辨率约 **256×256**；
- 只有 8 个离散潜在动作，动作语义不可直接解释，用户需要尝试才知道每个按钮的效果；
- 潜在动作虽可控，但不是真实机器人关节空间或标准游戏 API 动作；
- 长程几何、复杂物理和真实 sim2real 能力有限。

### 与通用视频生成模型的差异

- 增加了**无监督潜在动作推断模块**；
- 动力学模型按“动作 → 下一帧”条件化，而不是只根据文本生成一段视频；
- 生成单位从 clip 细化为可交互 step；
- 训练目标服务于控制和策略学习，而非单纯视觉质量。

## 4. Genie 2：大规模 3D foundation world model

- **官方发布**：Google DeepMind 博客，*Genie 2: A large-scale foundation world model*，2024-12-04
- **论文状态**：**截至本次调研，未检索到与 Genie 1 同等级的完整公开技术论文/arXiv 技术报告**；因此参数规模、训练数据时长、层数、训练调度、具体评测表均**查不到，不能编造**。

### 官方可核查信息

- 输入单张提示图像，生成可用**键盘和鼠标**控制的 3D 环境；
- 人类玩家或 AI agent 都可以在其中行动；
- DeepMind 将其描述为一个 **autoregressive latent diffusion model**；
- 官方强调的能力包括：
  - 动作可控的 3D 环境；
  - 物体交互、角色动画、光照、反射、NPC 行为；
  - **long-horizon memory**：例如记住视野外或之前探索过的场景元素；
  - OOD 泛化：概念图、手绘图也可变成可交互环境；
  - 可让 SIMA agent 在生成环境中执行开门、探索房屋等任务。

### 非论文来源给出的规格（需降权看待）

多个二手资料称：

- 输出约 **360p**；
- 多数演示环境保持约 **10–20 秒**连贯，DeepMind 称最佳情况下可到约 **1 分钟**；
- 实时体验通过蒸馏版本实现。

这些不是完整同行评议论文中的系统表格，应视为媒体/资料汇总。

### 局限

- 公开技术细节不足：参数量、训练集、推理算力和定量成功率均未公开；
- 典型连贯时长仍短，长会话中会出现物体漂移、纹理退化和几何不一致；
- 无持久可变世界状态的公开证据：它能“记住视觉布局”不等同于能永久保存物体被移动/破坏后的完整状态；
- 物理是从视频中学到的统计近似，不是保证接触、流体、布料或多体碰撞正确的物理引擎；
- 低分辨率和实时蒸馏会进一步限制仿真保真度。

### 与通用视频生成模型的差异

- 条件信号从一次性文本扩展为持续的键盘/鼠标输入；
- 使用自回归潜扩散框架进行下一步环境预测；
- 重点从镜头叙事质量转向 3D 一致性、可交互性和长时记忆；
- 但它没有传统游戏引擎中的显式 mesh、材质、物理对象和持久状态数据库；一致性主要来自权重中的先验与自回归上下文，而非可查询的场景图。

## 5. UniSim：学习交互式真实世界模拟器

- **论文**：*Learning Interactive Real-World Simulators*
- **编号**：arXiv:2310.06114；ICLR 2024
- **机构**：Sherry Mengjiao Yang、Yilun Du、Kamyar Ghasemipour、Jonathan Tompson、Dale Schuurmans、Pieter Abbeel；作者来自 Google/UC Berkeley 等
- **项目页**：universal-simulator.github.io

### 核心思想

UniSim 试图学习一个真实世界通用模拟器：给定当前观测和时间上延展的动作，预测真实的未来视觉结果。动作既包括：

- 高层语言指令，例如“打开抽屉”；
- 机器人低层控制；
- 人类活动；
- 导航动作。

论文的关键观察是：不同数据在不同维度上丰富：

- 图像/互联网数据：物体与外观丰富，但缺动作；
- 机器人数据：动作—观测对齐精确，但环境少；
- 第一视角人类活动：交互多样；
- 全景扫描和仿真导航：可提供相机运动与空间布局。

UniSim 通过统一动作表示和数据编排，把这些互补数据放在一起训练。文本动作用 T5 embedding 编码；可获得低层控制时，将归一化控制量拼接进动作条件。

### 架构

- 基于 video diffusion 的 **3D U-Net**，交替使用空间与时间注意力；
- 先低分辨率生成，再空间超分；
- 自回归滚动时，预测帧成为下一轮历史，以支持多步交互；
- 推理时可使用 classifier-free guidance 平衡条件遵循与生成多样性。

二手技术汇总称模型约 **5.6B 参数**、基础视频为 16 帧、低分辨率约 24×40、超分后约 192×320、训练使用 512 个 TPU-v3 约 20 天；这些具体规格建议以论文 PDF 正文/附录为准，本文不当作独立已复现实验。

### 实测与应用

- 能在多步操作中维持物体位置和状态，例如“拿起罐子 → 关抽屉 → 打开中间抽屉 → 放入橘子”；
- 从同一初始场景出发，不同语言动作会产生不同、看似合理的结果；
- 在 Language Table 中为高层视觉—语言策略生成长时轨迹；
- 论文报告纯仿真训练的策略可 zero-shot 部署到真实世界；
- PaLM-E 视觉—语言策略使用仿真数据后，相较短演示数据训练，距离目标缩减指标提升约 **3–4×**；
- RL 策略通过模拟器 rollout 和 REINFORCE 微调后，也可迁移到真实机械臂；
- 用 UniSim 生成视频训练 captioning，PaLI-X 在 ActivityNet Captions 上的 CIDEr 从 **15.2 提升到 46.23**（二手汇总引用论文结果）。

### 局限

- **幻觉/物理违背**：对不可能动作或不了解的可供性，可能生成看似真实但错误的结果；
- **记忆有限**：只条件化近期帧，难以处理长期记忆和复杂空间推理；
- **OOD 机器人形态/环境泛化不足**；
- 主要是视觉模拟器，缺少触觉、力觉等多模态状态；
- 分辨率和视觉保真度距离高保真游戏/机器人仿真仍有差距。

### 与通用视频生成模型的差异

- 从“文本 → 视频”改为“历史观测 + 统一动作 → 未来观测”；
- 支持语言高层动作和机器人低层控制；
- 训练目标直接面向闭环策略学习和 sim2real；
- 数据编排是核心贡献之一，而非只扩大同一类型文本—视频配对数据。

## 6. GameNGen：把扩散模型变成实时 DOOM 引擎

- **论文**：*Diffusion Models Are Real-Time Game Engines*
- **编号**：arXiv:2408.14837，2024
- **机构**：Google Research / Google DeepMind；Dani Valevski、Yaniv Leviathan、Moab Arar、Shlomi Fruchter
- **任务**：完全由神经模型交互式模拟经典游戏 DOOM

### 两阶段训练

1. **RL agent 采集数据**
   - 先训练强化学习 agent 玩 DOOM；
   - 记录大量动作和观测序列，作为扩散模型训练数据。

2. **扩散模型学习下一帧**
   - 复用小型 Stable Diffusion v1.4；
   - 条件输入为过去帧序列和动作序列；
   - 模型生成下一帧，并在推理时自回归滚动。

### 稳定性技巧

- **噪声化上下文帧**：训练时向编码后的历史帧加入高斯噪声，模拟推理时自回归产生的不完美上下文；
- 这让模型能修正上一帧采样中的错误，是长时视觉稳定性的关键；
- **微调 latent decoder**：只训练自编码器 decoder，用目标像素 MSE 改善游戏小字、HUD 和细节伪影。

### 实测结果

- 单块 TPU 上可超过 **20 FPS** 交互式模拟 DOOM；
- 下一帧预测 **PSNR 29.4**，接近有损 JPEG 压缩水平；
- 人类评估者区分短真实游戏片段和模拟片段时，只比随机猜测略好；
- 能在较长轨迹中保持游戏画面、移动和交互稳定性。

### 局限

- 针对 DOOM 单款游戏训练，泛化到其他游戏或真实世界并未由该工作证明；
- 本质是神经渲染/动力学近似，不维护传统 DOOM 引擎中可验证的完整游戏状态；
- 长时游玩仍可能积累漂移，关卡逻辑、碰撞和事件触发的正确性没有符号引擎式保证；
- “人类难分辨”限于短片段与实验设置，不能等同于完全无误的游戏引擎。

### 与通用视频生成模型的差异

- 明确的动作序列条件与逐帧预测；
- 训练时加入自回归上下文损坏，以提高闭环鲁棒性；
- 输出速度按实时交互标准设计，而不是离线生成；
- 数据由 RL agent 自主 rollout 采集，形成“会玩的 agent 产生训练环境数据”的闭环。

## 7. Sora：通用视频生成模型被阐释为“世界模拟器”

- **发布**：OpenAI，*Video generation models as world simulators*，2024-02-15
- **论文状态**：当时发布的是技术报告/博客，而非完整复现论文；许多训练细节未公开。

### 可核查机制与能力

- 将视频压缩到低维 latent space，再把 latent 切分为 **spacetime patches**；
- 以类似大规模 Transformer 处理 token 的方式扩展视频生成；
- 可原生处理不同分辨率、时长、宽高比和构图；
- 报告中展示长达约 60 秒的高保真视频；
- 在一些场景中表现出对象持久性、相机运动、材质反射、角色与环境互动等近似物理规律。

### OpenAI 自己指出的失败案例

技术报告明确提到模型可能：

- 不理解简单因果；
- 错误处理物体交互，例如咬饼干、玻璃/物体破碎；
- 产生空间方位混乱，例如左右混淆；
- 让物体随时间不自然出现或消失。

### 为什么它还不是完整世界模型

- 主要入口是文本/提示，不是每步到来的外部动作；
- 生成过程主要是开环，不提供可稳定查询的动作空间；
- 没有公开的持久状态、可编辑场景图或物理状态变量；
- 不能保证同一动作重复执行总产生一致后果；
- 报告的“世界模拟器”更像研究愿景：大规模视频预训练可能涌现物理直觉，而非已经实现可交互、可规划、可 sim2real 的模拟器。

### 与世界模型路线的关系

Sora 证明了大规模时空 patch + Transformer 的视频模型可以获得较强视觉与物理先验；但 Genie、UniSim、Cosmos、GameNGen 进一步补上的是动作接口、自回归闭环、记忆和决策评测。

## 8. 横向机制对比：动作条件、相机控制、记忆、长程一致性

| 模型 | 条件输入 | 生成方式 | 记忆/状态机制 | 长程一致性手段 | 主要用途 |
|---|---|---|---|---|---|
| SANA-WM | 首帧、文本、6-DoF 相机轨迹 | Hybrid linear diffusion DiT；双向或 chunk-causal | GDN 循环聚合 + 周期性 softmax attention | 原生一分钟训练、refiner、双分支相机条件 | 相机控制长视频/世界漫游 |
| Cosmos | 文本、过去视频、动作/相机位姿（后训练） | 扩散式与自回归式 WFM 并行 | 因果 tokenizer、Transformer 上下文；下游可接任务状态 | Video2World、后训练、插值器 | Physical AI、机器人、驾驶 |
| Genie 1 | 无监督离散 latent action | MaskGIT 自回归动力学 | 近期视觉 token + action embedding | 时空 tokenizer 与一致 latent action | 2D 可交互环境、模仿学习 |
| Genie 2 | 键盘、鼠标、首帧图像 | Autoregressive latent diffusion（官方描述） | Transformer 自回归上下文；官方强调 long-horizon memory | 大规模视频训练 + 自回归滚动；细节未公开 | 3D 可交互环境、agent 原型 |
| UniSim | 文本动作、机器人控制、历史帧 | 3D U-Net video diffusion + 超分 | 近期帧条件；无显式完整长期状态 | 自回归 rollout、多数据编排 | 真实交互仿真、sim2real |
| GameNGen | 过去帧、游戏动作 | Stable Diffusion 改造的下一帧扩散模型 | 历史帧/动作上下文 | 上下文噪声增广、decoder 微调 | 实时 DOOM 模拟 |
| Sora | 文本提示为主，支持不同时长/比例 | spacetime patches 上的大规模生成模型 | 未公开显式状态；主要靠模型上下文 | 大规模视频预训练；细节未公开 | 通用视频生成；世界模拟器愿景 |

### 8.1 动作条件的三种路线

1. **真实控制信号条件**：键盘、鼠标、机器人 action、车辆控制。
   - 优点：语义明确，可交互、可训练策略；
   - 难点：需要大量动作—观测配对数据。

2. **无监督 latent action**：Genie 1 从相邻帧中推断离散动作。
   - 优点：能利用海量无标签视频；
   - 难点：动作码不可解释，控制维度有限。

3. **语言动作/干预**：UniSim 的高层指令、Genie 3/后续系统中的 promptable events。
   - 优点：灵活，适合高层规划；
   - 难点：语言到低层物理状态的映射不稳定，难精确控制。

### 8.2 相机控制的两种粒度

- **全局轨迹条件**：把整段相机轨迹编码到 latent 条件中，保证运动方向和路径；
- **帧级几何条件**：Plücker ray、pose、extrinsics/intrinsics、深度或极几何约束，保证每帧细节。

SANA-WM 的双分支和 Cosmos 的 camera-pose 后训练说明：只给文本式“镜头向左”不足以成为精确世界模型，必须让几何条件进入网络。

### 8.3 记忆机制

现有系统主要依赖三类记忆：

1. **上下文窗口记忆**：把最近帧/动作 token 放入 Transformer；最简单但窗口有限。
2. **循环/线性注意力状态**：如 Gated DeltaNet 等，把历史压缩进循环状态，降低长序列成本。
3. **注意力长程召回**：softmax attention 可直接回看旧 token，但计算和显存成本高。

显式地图、3D 场景表示、对象数据库、可持久修改状态在上述多数纯生成系统中并未完整公开实现。Genie 2 的“记忆”尤其不能误解为传统游戏引擎式的持久世界数据库。

### 8.4 长程一致性与误差累积

自回归世界模型把自己的预测作为下一步输入，单步误差会复合：

- 短期表现为闪烁、纹理漂移；
- 中期表现为物体身份变化、布局变化；
- 重访地点时可能出现房间结构改变；
- 长期可能完全偏离初始世界。

已出现的缓解办法：

- 原生长视频训练，而非只训练短视频；
- 训练时噪声化/损坏历史帧，增强自校正能力（GameNGen）；
- 分块因果/滚动 KV cache/线性注意力；
- 第二阶段 refiner；
- 相机位姿和几何条件；
- 定期用真实观测 re-ground；
- 分层生成：全局布局/轨迹先确定，再生成局部细节。

## 9. “生成式世界模型”需要哪些额外架构能力？

### 9.1 显式且可扩展的动作接口

- 支持键盘/鼠标、相机 pose、机器人关节/末端执行器、车辆控制、语言干预等多模态动作；
- 动作空间应稳定：同一状态下同一动作产生一致、可学习的后果；
- 最好能连接低层连续控制与高层语言任务，而不是二选一。

### 9.2 因果、可滚动、可实时的生成骨干

- 当前时间步只能依赖现在和过去；
- 支持 frame/chunk 级自回归 rollout；
- 有低延迟采样、蒸馏、量化和 cache 机制；
- 交互场景中需要稳定 24 FPS 或更高，而不是离线几分钟生成一秒画面。

### 9.3 长期记忆与持久状态

需要超越短上下文，至少区分：

- 对象身份；
- 对象位置与可见/不可见状态；
- 场景布局和地图；
- 已经发生的状态变化；
- 多步任务历史；
- 其他智能体状态。

理想架构可结合生成模型与外部可写记忆，例如持久场景图、对象状态库、3D/4D 地图、可更新 latent state；但具体效果必须靠闭环实验验证。

### 9.4 几何与 3D/4D 一致性

- 相机内外参、metric scale、Plücker ray、深度、光流、位姿图等几何条件；
- 支持 novel view 与重访视角一致；
- 运动应符合遮挡、透视、视差和尺度关系；
- 长时序生成最好维护或约束隐式/显式 3D 表示。

### 9.5 物理规律与接触动力学

纯像素相关性不足以保证：

- 碰撞与接触；
- 支撑、摩擦、重力；
- 刚体、铰接体、布料、流体、可变形物体；
- 物体破碎、堆叠、推拉后的持续状态；
- 机器人动作的力学后果。

未来可行方向包括：物理先验约束、物理仿真器与生成模型混合、可微物理、显式对象状态/可供性建模，以及用真实机器人数据做闭环校正。

### 9.6 抑制自回归漂移

- 原生长序列训练；
- 历史帧噪声/扰动增广；
- diffusion forcing、chunk-causal attention、流式 KV/memory；
- 全局参考帧与局部滚动结合；
- 周期性真实观测再接地；
- 长时 consistency loss 与重访一致性评测。

### 9.7 面向策略学习的评测体系

通用视频常用 FVD、CLIPScore、人工美学评分；世界模型还需要：

- 动作跟随误差；
- 相机轨迹误差；
- 对象持久度；
- 重访一致性；
- 反事实动作的区分度；
- 物理违例检测；
- 在模拟器中训练策略后的真实世界成功率；
- 长时交互稳定性和实时延迟。

### 9.8 Sim2Real 与闭环数据飞轮

生成式世界模型若服务具身智能，应支持：

1. 策略在模型中安全探索；
2. 自动识别失败和稀有事件；
3. 回到真实世界采集关键校正数据；
4. 更新世界模型与策略；
5. 用真实部署成功率而不是仅用视频观感验证。

## 10. 总体判断

- **SANA-WM**代表高效、长时、精确相机控制路线，但主要是 camera-controlled world modeling，不是通用动作世界模型。
- **Cosmos**代表平台化 Physical AI 路线：数据、因果 tokenizer、扩散/自回归 WFM、后训练和 guardrail 一体化。
- **Genie 1**证明无标签视频也能学 latent action，但速度、分辨率和动作空间非常有限。
- **Genie 2**展示了单图生成 3D 可交互世界和长时记忆的潜力，但缺少完整公开论文，定量能力无法严格核验。
- **UniSim**把真实世界交互模拟和策略训练、sim2real 直接连接起来，是具身世界模型的重要早期代表。
- **GameNGen**证明扩散模型可在特定环境中实现实时、长程、动作条件游戏模拟，但高度针对 DOOM。
- **Sora**提供了强视觉/物理先验和“视频模型可成为世界模拟器”的范式启发，但缺少交互动作接口、持久状态和闭环保证。

最终趋势不是在通用视频 DiT 上单纯增加时长，而是形成：

> **动作/相机接口 + 因果生成骨干 + 可写长期记忆 + 几何/物理约束 + 自回归漂移控制 + 策略闭环评测 + sim2real 数据飞轮**。

这也是“视频生成模型”与“生成式世界模型”的根本分界。
