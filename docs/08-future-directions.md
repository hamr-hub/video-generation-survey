# 08 · 模型架构演进前景方向

> 判断基于 2024–2026 架构脉络（UNet→DiT→混合注意力；扩散↔自回归融合；生成→世界模型）。
> 按"确定性高→探索性强"排序。

## 8.1 注意力：混合化成为主流形态（确定性高）

- **"局部精确 Softmax + 全局双向线性/状态记忆 + 逐帧更新"** 定型。代表 VDN、SANA-Video 2.0、SLA。
- Full Attention 从"默认"变成**按位置策略性分配的昂贵资源**（类似 LLM 的 hybrid layer ratio）。
- 演进点：
  - 混合比例/放置由 **NAS / PostNAS 自动搜索**，而非手工。
  - 线性支路继续向 Gated DeltaNet / KDA 等更强状态更新器演进。
  - 数值可验证（bit-exact 布局 vs 近似算术）成为标配。

## 8.2 扩散 ↔ 自回归融合（高确定性，下一代底座候选）

- 两者互补：**自回归**强在多模态统一建模/理解/规划与可流式；**扩散**强在高保真、并行高效生成。
- 融合形态：
  - **分离扩散 / Masked 扩散 + AR 排序**：固定 sparse attention mask，带噪 patch 独立、可随机采样训练。
  - **AR 头 + 扩散解码器**：AR 出 token/结构，扩散在潜空间高保真还原（ARLON、ECCV'26 具身底座）。
  - **AR 缓存**：FlowCache 等给自回归视频生成加速（最高 6.7×，ICLR'26）。
- 目标：一个模型同时"理解 + 规划 + 生成"，且可任意顺序组合多模态。

## 8.3 原生统一多模态（MM-DiT 单流）（高确定性）

- 文本/图像/视频/音频/事件在**同一 token 空间、同一次去噪**里联合（H3 已验证）。
- 方向：更多模态（触觉、深度、3D、传感器）、任意模态互转、参考条件统一。
- 关键工程：多速率时间网格的统一位置编码（H3 三轴 → 更通用的时空坐标）。

## 8.4 长程 / 流式 / 连续生成（确定性中高）

- 从"固定短 clip"转向**任意时长、分块生成、上下文继承**（SANA-Streaming、LongSANA 27FPS、H3 的 24fps live 路线）。
- 依赖：恒内存状态（线性注意力累积态）、块间一致性、滑窗 KV。
- 终点：直播级实时 + 交互式生成（中途改 prompt/参考，下一段立即响应）。

## 8.5 生成 → 世界模型 / 物理一致性（确定性中，长线）

- 高质量生成不可避免要建模物理规律（因果、碰撞、材质、光照、6-DoF 运动）。
- 方向：SANA-WM、Cosmos 等具身/物理 AI 底座；可控相机与可交互环境。
- 架构需求：3D/场景表征、显式记忆、与动作/策略接口；生成服务于决策（sim2real）。

## 8.6 推理时计算与递归自我改进（确定性中）

- **Test-time scaling**：把更多算力放在推理阶段（多步精修、多候选、自我校验）。
- **RSI / Agent 化 kernel 优化**：agent 自动搜索 kernel 融合/布局/通信并做数值门控（Sol-H3、AlphaEvolve、AccelOpt 思路），减少人力。
- 编译与硬件协同设计（CUDA 图、FP8/FP4、专用 NPU）。

## 8.7 效率与边缘民主化（确定性高）

- 高压缩 token/VAE、一步/少步蒸馏（SANA-Sprint、一致性/DMD）、极致量化（FP8/NVFP4/FP4+AWQ）。
- 语言级/CPU 级重写（h3.c）、端侧 NPU 部署。
- 小模型靠"架构效率 + 外挂精修"逼近大模型，而非单纯堆参数。

## 8.8 总体判断

1. **主干**：DiT 不变，但内部注意力全面混合化、放置自动化。
2. **范式**：扩散与自回归从竞争走向**统一底座**（理解+规划+生成）。
3. **边界**：视频生成 → **原生多模态世界模型**，对接物理与具身决策。
4. **形态**：从短时一次性生成 → **实时、流式、可交互、任意时长**。
5. **约束侧**：少步蒸馏 + FP4 + RSI 自动优化，使能力持续向边缘下沉。

一句话：**"混合注意力的统一多模态世界模型，可流式、可交互、能推理、可被自动优化到边缘"** 是未来 2–3 年架构主轴。
